# FeedLens 0.2.0 release acceptance

The approved project's implementation evidence is recorded in
[`STANDARD_SCOPE.md`](STANDARD_SCOPE.md), [`LEGAL_INPUT_AUDIT.md`](LEGAL_INPUT_AUDIT.md)
and [`REVIEW_DATA.md`](REVIEW_DATA.md). Version 0.2.0 is the first release
candidate containing the later independent Atom Entry and common-standard
behavior. Mooncakes 0.1.0 is an older published snapshot; 0.2.0 was released
on 2026-10-28 UTC after the expanded behavior was merged into GitHub `main`.
The release passed `moon add youyong5/feedlens@0.2.0` in a separate module,
Wasm/JS/Native checks, and Native RSS, JSON Feed and independent Atom Entry
public calls. The published GitHub source commit was
[`6628ddb`](https://github.com/youyong5/FeedLens/commit/6628ddba9779864bcaa3b41ac35782fe0009da76),
with [six successful CI jobs](https://github.com/youyong5/FeedLens/actions/runs/40671619618).

## Before publication

1. Check that the GitHub `main` commit has green library, complete archived
   response, independent reference, external source consumer, and Native CLI
   jobs. Do not substitute a passing local test for the public CI run.
2. From the same clean checkout run `moon info`, `moon fmt`, then
   `moon check --target wasm/js/native`, `moon test --target wasm/js/native`,
   `python3 tools/check_external_consumer.py`, `moon package --frozen`, and
   `python3 tools/check_release_archive.py`. Inspect the exact
   `youyong5-feedlens-0.2.0.zip` generated by `moon package`.
3. Verify `moon whoami` is the owner of `youyong5/feedlens` and
   `moon view youyong5/feedlens` does not already list version 0.2.0.

## Publication and installation acceptance

From the verified `main` commit, run `moon publish` (without `--frozen`). The
publisher checks a freshly extracted archive, where dependencies must be
installed; `--frozen` blocks that fresh install even if the source checkout
has already passed `moon package --frozen`. Then verify
`moon view youyong5/feedlens --versions` lists 0.2.0 and the public
`https://mooncakes.io/docs/youyong5/feedlens@0.2.0` page exposes the intended
API. Finally run `python3 tools/check_published_consumer.py 0.2.0`.

On Windows without Python, the publisher can stop after `moon publish` and
share the result. The fresh-install check can be run on another machine with
Python and MoonBit; it does not require the publisher's credentials.

The published-consumer script creates an independent temporary MoonBit module
without `moon.work` or a symlink to this repository. It uses `moon add` for the
exact published version, checks Wasm, JavaScript and Native, then runs public
calls against RSS, JSON Feed with a numeric attachment, and an independent
Atom Entry with XHTML, author inheritance and source-aware URI resolution.
Only after that script passes can the release be called installed and usable.

Record the exact GitHub commit, CI run, `moon view` version and fresh-install
result in the release report. A successful archive validation alone proves
packaging, not a Mooncakes upload or downstream installation.
